Recept

Receptdata som JSON

Med receptlistan öppen: kopiera en .json-fil i Finder och tryck Cmd+V (Windows/Linux: Ctrl+V) var som helst i appen — ingen behöver klicka i rutan nedan. Du kan också klistra in rå JSON-text på samma sätt. Eller dra fil till rutan. Format: array […], objekt {…} eller {"recipes":[…]} med fält som id, title, groups, steps, tips m.m. Sparas lokalt; för GitHub Pages: lägg receptraden i RECIPES i källfilen och pusha.
